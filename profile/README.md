# Escape From The 6

**Engineering immersive experiences.**

We build custom software, electronics, and automation systems that bring interactive escape rooms to life.

Our work spans embedded controllers, interactive puzzles, real-time room management, lighting, audio, and physical effects.

### What we build

- **Room automation** — Coordinated control and monitoring of interactive environments.
- **Embedded systems** — Custom hardware and firmware for physical puzzles.
- **Interactive experiences** — Sensors, lighting, sound, and synchronized effects.
